Privacy Policy

Profit Data Bridge is a private analytics utility operated for the owner's own business-data workflow.

Google user data

The application requests Google Drive access only to create, locate, upload, and read back files used by the analytics workflow. The application does not use Google Drive access for advertising, profiling, or unrelated purposes.

Data stored

OAuth credentials required to maintain authorized access may be stored privately on the operator's server. Access tokens are used for API requests and are not intentionally exposed publicly. Analytics files created by the application are stored in the owner's Google Drive.

Sharing and sale of data

Google user data is not sold. The application does not share Google user data with advertisers or data brokers. Data is disclosed only when technically necessary to provide the application's own functionality or when required by law.

Retention and deletion

Files created in Google Drive remain under the Google account owner's control and may be deleted there. OAuth access can be revoked at any time through the Google Account permissions page. Locally stored OAuth credentials can also be deleted from the operator's server.

Security

The application uses OAuth credentials to access Google APIs and limits its requested scope to the functionality needed for the Drive-based workflow. Reasonable technical measures are used to keep credentials private.

Changes

This policy may be updated when the application's functionality or data practices change.
